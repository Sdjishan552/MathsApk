# MindMath (Android app)

Mental addition and subtraction trainer. GitHub builds the APK for you; no Android Studio needed.

1. Upload everything in this folder to the root of a GitHub repository (include the hidden `.github` folder).
2. Open the Actions tab. The "Build APK" workflow starts by itself (or click Run workflow). It takes about 5 to 8 minutes.
3. Open the finished run, scroll to Artifacts, download MindMath-APK, unzip it, and you get app-debug.apk.
4. Copy the APK to your phone and install it (allow "Install unknown apps" when asked).

Reminders: after 3 hours without practice the app sends a notification every 15 minutes until you solve 30 questions. Allow notifications when asked, and tap "Allow exact reminder timing" on the Practice screen for on-time alerts.

The app code is in www/index.html.
